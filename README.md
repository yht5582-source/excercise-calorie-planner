# 運動熱量消耗估算與智慧減重處方系統

可直接在瀏覽器使用的繁體中文單頁工具。依 2024 Adult Compendium 的 MET 值估算運動熱量消耗，並依減重目標、可運動天數、熱量赤字分攤與健康狀況，產生運動處方、每日建議攝取與安全提示。

## 線上使用

[開啟 GitHub Pages](https://yht5582-source.github.io/excercise-calorie-planner/)

## 功能

### 模式一：活動熱量即時估算

- 依體重、活動與持續時間估算總消耗與淨消耗熱量
- 44 項活動的 MET 與 5 位數代碼取自 2024 Adult Compendium（2026-10-10 核對）
- 顯示絕對強度分級，並換算成脂肪組織重量與常見食物份量

### 模式二：目標導向減重運動處方

- BMI（國健署分級）、Mifflin-St Jeor BMR、TDEE 與每日建議攝取
- 減重速度分級：同時看 kg/週與體重百分比
- 停止條件：未滿 18 歲、BMI <18.5、目標 BMI <18.5、運動警訊症狀
- 健康狀況可複選且條件會疊加：膝痛、心血管／腎臟病、高血壓、糖尿病（可勾選胰島素／促泌劑）、近期未規律運動，以及自動判定的 BMI≥30 與 ≥65 歲
- ACSM 2015 運動前篩檢
- 有氧處方：單次時間、每週總量（中等強度當量）與 WHO／ACSM 建議比較；不可行時反推所需週數或運動分攤比例
- 肌力與平衡訓練建議、依健康狀況分組的注意事項
- 複製處方摘要、列印衛教單
- 五組示例情境

計算公式、判斷規則與參考文獻見頁面底部的「計算方法、判斷規則與參考文獻」。

## 開發

- 單一 `index.html`；計算邏輯集中在 `/*ENGINE-START*/ … /*ENGINE-END*/` 區塊
- 規則測試：`node tests.cjs`
- 無外部套件，以 GitHub Pages 靜態部署（main 分支根目錄）

## 醫療與安全聲明

本工具供健康促進、衛教與個人規劃參考，不能取代醫師、物理治療師、營養師或其他合格醫療專業人員的個別評估與處方。MET、熱量赤字、脂肪換算及運動時間均為模型估算，處方規則未經前瞻驗證。患有慢性病、心血管症狀、關節疼痛，或運動時出現胸痛、明顯喘促、暈眩等不適者，應停止運動並尋求專業評估。
