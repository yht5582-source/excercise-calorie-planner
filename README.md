# 運動熱量消耗估算與智慧減重處方系統

一個可直接在瀏覽器使用的繁體中文單頁工具，依身體活動代謝當量（MET）估算運動熱量消耗，並依減重目標、可運動天數、熱量赤字分配與健康狀況，產生運動安排建議。

## 線上使用

[開啟 GitHub Pages](https://yht5582-source.github.io/excercise-calorie-planner/)

## 功能

### 模式一：活動熱量即時估算

- 依體重、活動類型、MET 與持續時間估算總消耗與淨消耗熱量
- 顯示低、中、高運動強度
- 將淨消耗換算為脂肪組織重量與常見食物熱量份量
- 內建步行、跑步、自行車、水中運動、阻力訓練、球類及家務活動

### 模式二：目標導向減重運動建議

- 計算 BMI、每週目標減重速率與每日所需熱量赤字
- 可設定運動與飲食的熱量赤字分攤比例
- 依每週可運動天數換算單次運動時間與淨消耗目標
- 提供一般健康、膝關節或下肢疼痛、心血管或高血壓、糖尿病或代謝異常、運動新手及高體重負荷等選項
- 顯示減重速度警示、運動建議與漸進式執行提示
- 內建四組快速載入的示範情境

## 計算方式

- 總消耗熱量：`MET × 體重（kg）× 時間（小時）`
- 淨消耗熱量：`(MET − 1) × 體重（kg）× 時間（小時）`
- 減重目標換算：以每公斤脂肪組織約 `7,700 kcal` 估算所需熱量赤字
- 單次運動時間：依每週運動赤字、運動天數、建議活動 MET 與體重估算

所有結果皆為估算值，實際能量消耗會受到個人代謝、體組成、運動效率與健康狀態影響。

直接開啟 `index.html` 即可使用，不需要安裝套件、建置流程或後端服務。網頁資料與計算均在使用者的瀏覽器內完成。

## 醫療與安全聲明

本工具供健康促進、衛教與個人規劃參考，不能取代醫師、物理治療師、營養師或其他合格醫療專業人員的個別評估與處方。MET、熱量赤字、脂肪換算及運動時間均為模型估算，不代表實際減重結果。患有慢性病、心血管症狀、關節疼痛，或運動時出現胸痛、明顯喘促、暈眩等不適者，應停止運動並尋求專業評估。
